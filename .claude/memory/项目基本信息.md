## 工作方式
- 用户编写 `生成方案N.txt`（N 为数字序号）来逐步丰富网站
- 每次方案包含：新增/修改内容描述、交互需求、视觉偏好
- 迭代更新 `index.html` 和 `style.css`，保持原有设计风格一致

## 版本管理
- 每次迭代前，将当前 `index.html` + `style.css` 备份到 `历史版本/YYYY-MM-DD_vN_简短描述/`
- `历史版本/README.md` 记录每个版本的日期、内容和触发方案
